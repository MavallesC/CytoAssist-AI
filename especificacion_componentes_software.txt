2. DESCRIPCIÓN POR CAPAS DEL SISTEMA
================================================================================

2.1. Capa Web y Persistencia:
  - Django 5.2.17: Proporciona la estructura modular backend, autenticación,
    ORM para consultas de datos estructurados, transacciones atómicas para
    asegurar consistencia diagnóstica, y servidor web interactivo.
  - SQLite 3: Base de datos relacional ligera integrada que almacena metadatos
    de láminas WSI, coordenadas de ROIs y el inventario celular clasificado.

2.2. Capa de Inteligencia Artificial (Modelos y Clasificación):
  - Backbone DenseNet-121 (PyTorch 2.9.1): Red profunda convolucional pre-entrenada
    y afinada con el dataset CRIC Cervix Collection, vector latente de 1024 dims.
  - Clasificador CatBoost (v1.2.10): Modelo de árboles de gradiente (500 iteraciones,
    depth=6, lr~0.059) para predecir las 6 categorías Bethesda:
    1. NILM (Negativo para lesión intraepitelial o malignidad)
    2. ASC-US (Células escamosas atípicas de significado indeterminado)
    3. LSIL (Lesión intraepitelial escamosa de bajo grado)
    4. ASC-H (Células escamosas atípicas, no se descarta alto grado)
    5. HSIL (Lesión intraepitelial escamosa de alto grado)
    6. SCC (Carcinoma de células escamosas)

2.3. Capa de Visión Artificial y Procesamiento WSI:
  - Tifffile 2026.6.1 + ImageCodecs 2026.6.6: Apertura y lectura estriada de imágenes
    gigapíxel escaneadas por MoticEasyScan One sin saturar la RAM mediante memmap.
  - OpenCV 4.12.0.88: Segmentación en espacio de color HSV (separación de tejido vs.
    artefactos de tinta/burbujas) y cómputo de nitidez mediante varianza del Laplaciano.

2.4. Capa Frontend e Interfaz Clínica:
  - HTML5 & CSS3 (Vanilla Dark Mode): Interfaz médica estilizada de alto contraste.
  - JavaScript (ES6+): Monitoreo asíncrono en tiempo real y descarga de recortes ZIP.
