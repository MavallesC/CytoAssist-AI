Instrucciones para Colocar Modelos Reales
Para habilitar la clasificación real, asegúrese de copiar los siguientes archivos a la carpeta artefactos/ en el directorio raíz de este proyecto:
  • inference_artifacts.json (archivo de mapeo y rutas).
  • El archivo de pesos de PyTorch correspondiente al backbone extractor (ej. densenet121_backbone.pt).
  • El clasificador entrenado de CatBoost (ej. catboost_classifier.cbm).
  • El archivo pca.joblib (si el pipeline fue configurado con PCA).
